## 2024-05-18 - Standardize Log Emojis for Better Scannability
**Learning:** Using multiple different emojis for identical log levels (like 'INFO') creates visual noise and reduces scannability in CLI outputs and syslogs.
**Action:** Stick to a consistent, limited set of emoji prefixes based on the log's intent (e.g., exclusively 'ℹ️' for standard info logs) rather than using context-specific decorative emojis.
