## 2024-09-07 - Emoji Semantics for Empty States vs Exclusions
**Learning:** Users interpret emojis differently based on context. Using the skip track emoji (⏭️) for both intentional exclusions and structural empty states (like missing configs) causes confusion, making structural bypasses look like active user exclusions.
**Action:** Use the fast-forward emoji (⏩️) for structural empty states (missing dependencies, configs) to imply an efficient, intentional bypass, reserving the skip track emoji (⏭️) exclusively for items explicitly excluded by user configuration.
