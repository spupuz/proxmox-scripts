## 2024-05-24 - Actionable CLI Error Messages
**Learning:** Generic error states in CLI outputs and notifications increase user friction because the user has to guess what went wrong. Providing an immediate, context-aware hint reduces confusion and support requests.
**Action:** Always pair generic error states (e.g., "Telegram Error", "Invalid tag format") with actionable hints (e.g., "(Check network or bot token)", "(Expected vX.Y.Z)") to guide the user towards a quick resolution.
