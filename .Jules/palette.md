## 2024-10-10 - Structural Empty States vs. Exclusions
**Learning:** In bash script CLI output and notifications, the fast-forward emoji (⏩) conveys an intentional structural bypass (e.g., missing dependencies, no containers, 0 items updated) much better than a skip-track (⏭️). The skip-track should be exclusively reserved for items explicitly bypassed via user configuration (e.g., excluded containers).
**Action:** Always differentiate empty/bypassed states using ⏩ for structural bypasses and zero-aggregates, and ⏭️ for user-configured exclusions.
