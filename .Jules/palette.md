## 2024-10-11 - Aggregate Empty States
**Learning:** Structural empty states (e.g. '0 B' or '0') for aggregate statistics should use the fast-forward emoji (⏩) as per UX standards, NOT ⏭️ which is for explicit exclusions.
**Action:** Use fast-forward emoji (⏩) instead of checkmarks (✅) or skip-track (⏭️) for empty aggregates, explicitly logging them.
