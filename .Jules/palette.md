## 2024-05-24 - Empty State Fast-Forward Icon
**Learning:** Empty states should feel intentional and fast, not like skipped errors. The fast-forward icon (⏩️) implies the system efficiently processed the empty state and moved on, whereas skip track (⏭️) implies ignoring a valid item.
**Action:** Always use ⏩️ for structural empty states (like "no containers") and reserve ⏭️ for explicitly excluded items.
